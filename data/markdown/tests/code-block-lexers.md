# Code block lexers

A shell session on one line used to draw an empty block.

```console
$ gem install stripe
```

A shell session on two lines used to lose its second line.

```console
$ gem install stripe
Successfully installed stripe
```

YAML used to crash the render, on a token type no style lists.

```yaml
name: md2ui
version: 1
features:
  - code blocks
```
