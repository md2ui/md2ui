# Per-file line ceilings. Anything not listed gets the default of 500.
#
# THE LINE COUNT IS A PROXY. It is not a quality standard and hitting it is not a
# defect. What it watches for is code concentrating in one file for no reason --
# the failure this project actually had. A file that is genuinely one concept is
# allowed to be long, and splitting a coherent file to satisfy a number erodes
# the code to protect the metric.
#
# So exceeding a ceiling is a PROMPT, not a verdict. Two honest answers:
#   * it holds more than one concept  -> split it along a seam, lower the number
#   * it is one concept               -> raise the number here, with the reason
#
# A file may shrink freely; `make check` reports slack so a gain can be locked in
# with `make ratchets-lower`. Numbers below the default line are inherited from
# before the restructure and carry no judgement. Numbers above it are decisions,
# and each one says why.
