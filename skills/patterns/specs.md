# Specs

**Use for:** 3–6 attributes of one thing. **Not for:** several things side by side (`comparison`) or figures that changed (`kpis`).

```markdown
## Specifications

_Weight_
1.4 kg

_Battery_
12 hours

_Screen_
14 inches

_Storage_
512 GB

_Warranty_
2 years

`Water resistant` `Fast charging` `Backlit keys`
```

**Why each marker**
- Each attribute is its label, muted, over its value, a blank line apart: the pairs repeat as one set — `text.md`.
- A chip run holds yes/no features, which are metadata — `text.md`.
- Escape a value's punctuation (`\%`, `\$`) when it should stay text — `structure.md`.
