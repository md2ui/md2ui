# Features

**Use for:** 2–6 things a product or plan does, each said as what the user gets.
**Not for:** offerings with tags and a way into each (`services`); attributes and their values (`specs`); priced options (`listing`).

```markdown
## What Ledgerly does for you

*🧾*
### Receipts file themselves
Snap a receipt and it lands under the right expense, matched to the card charge.

*📊*
### Spending at a glance
Each category's month so far, beside what you planned for it.

*🔔*
### Bills before they are due
A reminder three days ahead, with the amount and the account it leaves from.
```

**Why each marker**
- Each feature is a `### ` card: the icon above its title, one line under it — `structure.md`.
- The icon is the one the feature is about, in the theme's spelling: `guide("theme")`. An SVG icon from the product works the same, with a size and `aspect_ratio=1:1` — `images.md`.
- A blank line between features makes each a group; the repeated shape grids — `repetition.md`.
- The `## ` title names what the run is for; the cards carry no action, since the page's action follows them.
