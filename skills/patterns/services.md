# Services

**Use for:** 2–8 offerings the user browses: what each is, what it covers, where to go next.
**Not for:** things priced and chosen side by side (`listing`, `offer`); a menu of places in the app (`shortcuts`).

```markdown
## What the studio offers

### Portrait sessions
Natural-light portraits for people, pets and families.
`Studio` - `Outdoor` - `Headshots`
[`Book a session →`](agent:book?service=portraits)

### Event coverage
Weddings, launches and conferences, from first guest to last dance.
`Weddings` - `Corporate` - `Live edits`
[`See packages →`](agent:open?service=events)
```

**Why each marker**
- Each service is a `### ` card, its name the title and one line on what it is under it — `structure.md`.
- What it covers is a run of chips on one line: static tags the user scans — the core note's element table.
- The way in repeats on every card, so it reads quiet; its spelling is the theme's, `guide("theme")`.
