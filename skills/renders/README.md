with the current build, the build is right.

**Open the 700 and the 1600 beside each other before sizing a board.** They are the same
document and the same theme; only the width differs, and the narrower one gives its cards
more room.

**Look at the boards before deciding something is out of reach.** What came out well did
because the document was shaped right, not because anything was positioned.
